# AI Career Guidance Automation System

## Project Overview

The AI Career Guidance Automation System is a workflow automation project that helps students receive personalized career guidance based on their interests and career goals. The system eliminates the need for manual counseling by automatically collecting student information, generating AI-powered career recommendations, and sending the guidance directly to the student's email.

The project uses Google Forms for data collection, Google Sheets for storing responses, Zapier for workflow automation, Gemini AI for generating personalized recommendations, and Gmail for email delivery.

This solution demonstrates how Artificial Intelligence and automation tools can be integrated to create an efficient and scalable career guidance system.

---

## Problem Statement

Many students are unsure about the skills, resources, and next steps required to achieve their career goals. Providing individual career guidance manually can be time-consuming and difficult to scale.

This project addresses that challenge by automatically generating personalized career suggestions based on the information provided by students.

---

## Project Objectives

The main objectives of this project are:

* Collect student information through an online form.
* Understand students' interests and career aspirations.
* Generate personalized career guidance using AI.
* Automate the entire process without human intervention.
* Deliver guidance directly to students through email.
* Demonstrate the practical use of workflow automation and AI integration.
